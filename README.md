# ApnoAI Project First Client — Computer Training Institute

This is a responsive, single-file HTML/CSS/JavaScript demo website for the ApnoAI "Project First Client" task.

## Important before publishing
The business name "NextGen Computer Academy" and all contact details are placeholders. Replace them with verified details from a real business, or clearly label the site as a demo portfolio project. Do not publish invented phone numbers, addresses, course durations, student testimonials, admissions claims, or facilities as real facts.

## Features
- Responsive navbar with mobile menu
- Hero section
- Courses section (6 sample course cards)
- About section
- Why-us section
- Testimonial placeholder
- Contact section
- Dark mode toggle
- Enquiry form validation and demo toast (does not send data anywhere)
- Responsive layouts for desktop/tablet/mobile

## Run locally
Open `index.html` in Chrome, or use VS Code Live Server.

## Deploy
1. Create a public GitHub repository, e.g. `apnoai-final-computer-institute`.
2. Upload `index.html` and this `README.md`.
3. Import the repo in Vercel.
4. Set Framework Preset to **Other**; leave build command empty; output directory can be left default/empty for static HTML.
5. Deploy and test the live URL on desktop and mobile.

## Real form
The current form only validates input and displays a confirmation toast. It does not send an enquiry. Connect Formspree or a backend before using it for a real business.
